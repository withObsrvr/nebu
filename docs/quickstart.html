Install nebu, install token-transfer, stream JSON, then query the output with DuckDB.

Open on asciinema →

1. Install the CLI

$ go install github.com/withObsrvr/nebu/cmd/nebu@latest
$ export PATH="$HOME/go/bin:$PATH"
$ nebu --version

Requires Go 1.23 or later and your Go bin directory on PATH.

Copied!

2. Install your first processor

$ nebu list
$ nebu install token-transfer

The CLI embeds the registry and installs processor binaries on demand.

3. Stream events

$ token-transfer --start-ledger 60200000 --end-ledger 60200001

You should see newline-delimited JSON events on stdout.

{"_schema":"nebu.token_transfer.v1","meta":{"ledgerSequence":60200000},"transfer":{"assetCode":"USDC","amount":"1000000"}}

4. Filter with jq

$ token-transfer --start-ledger 60200000 --end-ledger 60200100 | \
jq 'select(.transfer.assetCode == "USDC")'

5. Aggregate with DuckDB

$ token-transfer --start-ledger 60200000 --end-ledger 60200100 | \
duckdb -c "SELECT COUNT(*) AS transfers FROM read_json('/dev/stdin') WHERE transfer IS NOT NULL"

6. Separate fetch from processing

$ nebu fetch 60200000 60200100 > ledgers.xdr
$ cat ledgers.xdr | token-transfer | jq .

Preview without setup

If you only want to see output first, you can run the published Docker image. Treat this as a preview path for now, not the main local install flow.

$ docker run --rm withobsrvr/nebu:latest \
token-transfer --start-ledger 60200000 --end-ledger 60200001
