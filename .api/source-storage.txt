package storage // import "github.com/withObsrvr/nebu/pkg/source/storage"

Package storage provides a LedgerSource implementation backed by a Stellar
datastore (GCS, S3, FS).

This package implements the source.LedgerSource interface from the parent
pkg/source package. Importers pay the full cost of the Stellar datastore and
cloud SDK dependencies (AWS SDK, GCS client); code that only needs the interface
should import pkg/source directly.

func (s *LedgerSource) Close() error
    Close implements source.LedgerSource.Close.

    There is nothing to release: a LedgerStream opens the datastore on the first
    pull of a Stream call and closes it when that iteration ends, so a source
    that is not streaming holds nothing open. Close remains part of the contract
    and stays safe to call at any time.

func (s *LedgerSource) LedgerWindow(ctx context.Context) (source.LedgerWindow, error)
    LedgerWindow implements source.WindowedSource.

    The window is what has been *exported*, not what exists on the network.
    An exporter runs behind the tip, so "the last 100 ledgers" from an archive
    is a different hundred than from an RPC endpoint — which is why a caller is
    expected to report the range it resolved rather than just the count.

    This opens its own datastore: the stream opens one on the first pull and
    does not expose it. Finding the oldest ledger is a binary search over the
    object listing, so this costs a bounded handful of round trips — paid once
    at startup, against a backfill that will run far longer.

func (s *LedgerSource) Stream(
	ctx context.Context,
	start, end uint32,
	out chan<- xdr.LedgerCloseMeta,
) error
    Stream implements source.LedgerSource.Stream. Supports both bounded and
    unbounded ranges:
      - Bounded: start > 0, end > 0 (streams ledgers from start to end)
      - Unbounded: start > 0, end == 0 (streams ledgers from start continuously)

func (s *LedgerSource) StreamRaw(
	ctx context.Context,
	start, end uint32,
	fn source.RawLedgerFunc,
) (uint32, error)
    StreamRaw implements source.RawLedgerSource.StreamRaw.

    Unlike the RPC source there is no per-range stream selection: the buffered
    storage stream reads the datastore manifest for the bucket's real layout
    when it opens, so its sizing already tracks the data rather than the range.
